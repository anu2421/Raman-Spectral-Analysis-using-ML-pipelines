# Data (not uploaded)

The raw spectra are not shared. Put each cell line's folder here:

```
data/A549/   CONTROL, E.COLI Heat inactivation, E.coli sonication,
             S.aureus heat inactivation, S.aureus sonication
data/K562/   CONTROL, E.COLI-Sonication, E.COLI-heat inactivated,
             S.aureus- sonication, S.aureus- heat inactivated
```

Inside each condition folder, the CSVs can be in R1 / R2 / R3 subfolders or named R1_..., R2_... .
